📊 Claude Session Report

Click «+ Add source» and register one or more log folders. Each is saved and loaded together; use the Source filter to view one at a time.

Supported folders:
• Claude logs — C:\Users\your_User\.claude\projects (*.jsonl)
• context-lens — C:\Users\your_User\.context-lens\data (state.jsonl with system prompts & tools, and .lhar exports)
• any other folder of Claude-style *.jsonl logs (e.g. abap-ai)

Sources are remembered — next time one click loads them all.
